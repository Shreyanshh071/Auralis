### Highlights & Features

- **Streaming & Discovery**: YouTube Music streaming, background playback, and search with network-dependent stream resolution.
- **New User Experience**: An Olive Green / Auralis Lime theme and a curated starter set of music suggestions.
- **Adaptive Recommendations**: Listening-history-based recommendations, Speed Dial, Similar to Artist/Song shelves, and Daily Discoveries.
- **Noise & Spam Filter**: Heuristics reduce non-music, sleep-noise, and spam recommendations; some unwanted results may still appear.
- **Synchronized Lyrics**: Timed lyrics and karaoke-style scrolling when a matching timed source is available.
- **Listen Together**: Playback coordination across devices; timing depends on network and loading conditions.

`Auralis.apk` and `Auralis-v1.0.0-universal.apk` are the same build. For the latest fixes, download the [current release](https://github.com/Shreyanshh071/Auralis/releases/latest).

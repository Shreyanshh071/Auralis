# Auralis 1.1.1

## Fixed

- Background playback keeps the mini-player and media notification available.
- Downloaded queues stay in offline playback mode.
- Spotify artwork is preserved when matching songs to YouTube for playback.
- Playlist reordering starts only from the drag handle.
- Lyrics preserve full wording and handle defective word timing more reliably.
- Account deletion cleans up associated cloud data and Listen Together references.
- Listen Together cleans up membership and votes when listeners leave, and room data when the host closes the room.

## Added

- Playlist downloads with progress, folder display and removal controls.
- Playlist order locking.
- Playlist listening statistics and Speed Dial support.
- YouTube account and playlist picker in the import screen.
- Listen Together cleanup retries and warnings before alone/idle rooms close.

## Improved

- Search ranking and filtering of identifiable Shorts during imports.
- Imported playlist identity, helping keep similarly named playlists separate.
- Lyrics scrolling, alignment, blur presentation and re-sync.
- Player, profile, playlist and floating notification UI.
- Account isolation and cloud cleanup coordination.
